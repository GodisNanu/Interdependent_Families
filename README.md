# IF (Interdependent Families)

## About the Project

This application is built for a virtual homeschool co-op.  It has 2 pages.  

The homepage includes basic information about the co-op along with all the current classes which is updated as classes are added to the server.

The profile page includes a custom calendar which populates after a call is made to the google calendar API. This will show all the classes the user is enrolled in. 

## Features

-The user can enroll in the co-op by clicking the enroll button, specific classes, or advertisements on the page
-The user can sign in and sign out securely
-The user can access their profile and class scedule
-The user can request and add new classes

## Tech Stack

HTML, CSS, JAVASCRIPT, REACTJS, JSX, REST API, GITHUB, FIGMA, JSON
